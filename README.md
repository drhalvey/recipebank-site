# recipebank.app

Website for Recipe Bank (iPhone): landing page, privacy, terms and help, shared recipe pages (`/r/?id=…`) and the web version (`/my/#<private key>`).

- Static site served by GitHub Pages, custom domain recipebank.app (DNS at Cloudflare).
- Pages are generated by `_build/make.py`; shared styles and the recipe viewer are in `assets/`.
- Data: the Supabase edge function `recipebank` in project ed-diary-feed (source copy in `_backend/`). Shared recipes themselves live on the Recipe Bank Cloudflare Worker.
- `/.well-known/apple-app-site-association` lets `/r/*` links open the app.
